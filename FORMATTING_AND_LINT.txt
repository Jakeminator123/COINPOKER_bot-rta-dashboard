Formatting & linting layout (monorepo)
-------------------------------------

- Root (detection tool, Python):
  * VS Code/Cursor settings: terminal cwd=root, Python interpreter set to C:\Program Files\Python313\python.exe.
  * No formatter forced here; Python language server is Pylance (per .vscode/settings.json).
  * Use your usual Python formatter/lint (e.g., Ruff/Black) if desired; nothing in root auto-formats TS/JS.

- Dashboard (site/bot-rta-dashboard):
  * Has its own .vscode/settings.json inside the dashboard folder.
  * Default formatter: prettier-eslint (rvest.vs-code-prettier-eslint) with formatOnSave enabled for TS/TSX/JS/JSX.
  * ESLint is enabled; fixAll runs only when explicitly triggered (codeActionsOnSave source.fixAll.eslint = explicit).
  * TypeScript SDK points to node_modules/typescript/lib in that folder.

How to avoid conflicts:
- Let Prettier handle formatting; ESLint handles linting. eslint-config-prettier should be in the project to disable conflicting rules.
- If you need to run lint manually: from site/bot-rta-dashboard, use npm run lint (or npm run lint -- --fix).
- Keep the two .vscode folders separate (root vs site/bot-rta-dashboard/.vscode); the dashboard settings do not override the root Python project.
